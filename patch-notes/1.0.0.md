- KubeJS fluid type `amcore:molten` for molten metals: thick, slow-flowing and glowing, it sets entities on fire and
  damages them on contact. Scripts can set `lightLevel`, `burnSeconds` and `burnDamage`.
- Molten damage type with its own death messages. It counts as fire damage, so Fire Resistance protects against it.
- Mod logo.
- English and French translations.
